# Bar-o-Express

Projeto Bar-o-Express.

## Sobre

Este repositório guarda o código e os arquivos do projeto Bar-o-Express.
Todo o histórico de mudanças fica registrado aqui, e cada alteração pode
ser revisada antes de entrar na branch principal (`main`).

## Como contribuir

1. Crie uma branch a partir da `main`.
2. Faça suas alterações e registre-as com commits de mensagem clara.
3. Envie a branch para o GitHub e abra um Pull Request (PR).
4. Revise o PR e, se estiver tudo certo, faça o merge na `main`.
